Follow the data

Form entries: held in this page’s memory while it is open. This code does not use cookies, browser storage, analytics, external fonts or network requests. Clear removes entries and the displayed receipt from this page. Reloading resets the demo; browser autofill and restoration may behave differently.

Hosting: opening a hosted page still requests the page from its host, which may record technical information such as IP addresses. That is separate from sending form entries.

Downloads: only happen when you choose to download. Clearing this page does not delete a downloaded file.

Before this becomes real registration

This is a design proposal, not a working membership service or an audited security guarantee. Real registration needs secure authentication and server-side controls, a published privacy notice and terms, defined retention, accessible account deletion and a working human support route. Any AI provider and data handling must be explained before connection.

AI helped create this prototype. Review its source and test its behaviour. A page can demonstrate accountable design; it cannot prove that every AI system is trustworthy.
